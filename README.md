# Photo Gallery

A responsive photo gallery built with React and Tailwind CSS.

## Features
- Fetch photos from Picsum API
- Loading spinner and error handling
- Responsive grid layout
- Real-time author search
- Add/remove favourites
- Save favourites using localStorage
- Custom hook: `useFetchPhotos`
- `useCallback` and `useMemo` for performance
- `useReducer` for favourite management

## Tech Stack
- React
- Tailwind CSS
- JavaScript
- Picsum Photos API

## API
https://picsum.photos/v2/list?limit=30
